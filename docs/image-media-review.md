# دليل الميديا المعتمد

تم استبدال المراجعة الأولية بدليل موحّد يعكس مسار تجهيز الميديا للإطلاق.

- [دليل الرفع للمصمم ومسؤول الداشبورد](../../yalla_backend/docs/MEDIA_UPLOAD_GUIDE.md)
- [قائمة اعتماد الميديا مع كل إصدار](../../yalla_backend/docs/MEDIA_RELEASE_CHECKLIST.md)

مصدر المواصفات النهائي هو `GET /api/v1/dashboard/media-specs/`. الرفع الأصلي للصور حتى 5MiB وللفيديو حتى 30MiB و30 ثانية؛ التجهيز على السيرفر، والنسخة المنشورة للفيديو حتى 15MiB. راجع الدليل المعتمد للمقاسات والقص والمعاينة وخطوات النشر.
